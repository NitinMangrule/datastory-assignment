# Country Insights Dashboard 📊

A data visualization dashboard built with **Next.js**, **TypeScript**, **Chakra UI**, **Apollo Client**, and **GraphQL**. It allows users to select a country and a measure to visualize data dynamically using a chart.

---

## 🌐 Tech Stack

- **Next.js** – React framework for SSR/SSG
- **TypeScript** – Strong typing and safer development
- **Chakra UI** – Accessible component library for styling
- **Apollo Client** – GraphQL client for data fetching and caching
- **GraphQL** – Flexible API query language
- **React Chart.js 2** – Chart rendering library
- **GraphQL Code Generator** (optional) – Auto-generates types from GraphQL queries
